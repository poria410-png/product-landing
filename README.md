# 🎧 Alpha Pro X - Product Landing Page

A sleek, modern, dark-mode single product landing page for "Alpha Pro X" wireless earbuds. Built with HTML5, CSS3 (Flexbox & CSS Grid), and ES6+ JavaScript.

🌐 **Live Demo:** https://poria410-png.github.io/product-landing/

---

## ✨ Key Features

- **Dark Mode UI:** High-contrast neon aesthetics tailored for gaming and tech products.
- **Interactive Image Gallery:** Dynamic product image switcher driven by vanilla JavaScript.
- **CSS Grid Features Layout:** Clean, responsive grid displaying key specifications.
- **Order Form & CTA:** Structured checkout section with interactive form fields.
- **Mobile-First & Fully Responsive:** Optimized layout across all screen sizes.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure & web accessibility
- **CSS3** – Custom variables, CSS Grid, Flexbox & smooth transitions
- **JavaScript (ES6+)** – DOM manipulation for gallery interactivity
- **GitHub Pages** – Deployment & hosting
